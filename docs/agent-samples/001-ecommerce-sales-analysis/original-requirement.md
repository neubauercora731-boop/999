## Requirement Summary

实验名称：电商销售数据综合分析（8 大方法实战）。

实验数据：`online_sales.csv`。

实验环境：Python 3.x。

原始任务要求使用：

- `pandas`
- `matplotlib`
- `seaborn`
- `statsmodels`

需要完成的数据分析方法：

1. 数据读取与基本预处理：读取 CSV，检查完整性，转换日期格式。
2. 描述性分析：对商品单价、销量、销售额计算均值、中位数、标准差等指标，绘制箱线图。
3. 分组分析：按商品品类、销售渠道、省份统计销售额、销量、平均单价。
4. 结构分析：计算各品类、渠道、省份销售额占比，绘制饼图。
5. 分布分析：分析销售额、单价、销量分布特征。
6. 对比分析：从渠道、月份、品类等维度绘制柱状图与折线图。
7. 简单线性回归分析：以销量为自变量、销售额为因变量，输出回归方程并预测。
8. 时间序列分析：按月份构建销售额序列，绘制时序图，进行分解和未来走势预测。

原始任务还要求结果以截图形式展示，并配文字说明；报告中需要包含实施过程、结果分析、问题及思考。
