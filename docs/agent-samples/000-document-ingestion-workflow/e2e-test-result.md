## Fixes Made During E2E

1. Non-standard docx fallback
- Added explicit docx zip-error fallback to `word-extractor`.
- Added user-visible warning.

2. Moonshot structured JSON robustness
- Replaced strict `callMoonshotJson` failure behavior in document ingestion with:
  - JSON extraction from model text
  - alias normalization
  - loose array coercion
  - schema validation
  - deterministic fallback structured task if JSON/validation fails

3. Missing `task_files.parsed_text` column compatibility
- Current local DB stores file text in `metadata.parsed_text`.
- Code now avoids writing missing `task_files.parsed_text` directly.
- Analyze context also reads `metadata.parsed_text`.

4. Missing `task_outputs.docx_url` column compatibility
- Current local DB does not have `task_outputs.docx_url`.
- Code no longer writes that column.

5. Old task status enum compatibility
- Current local DB supports older task statuses such as `waiting_confirm`.
- Code retries status updates with old-compatible status values if the newer status fails the DB check constraint.

6. Old task run type enum compatibility
- Current local DB does not allow `confirm_analysis`.
- Code maps newer run types to compatible legacy run types when the DB rejects them.
