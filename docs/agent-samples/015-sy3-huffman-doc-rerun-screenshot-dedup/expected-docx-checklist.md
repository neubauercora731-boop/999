# DOCX Checklist

- Original teacher-provided content remains present.
- `【代码】` exists.
- `【运行截图】` exists.
- `【问题及思考】` exists.
- The final DOCX does not contain `系统填写`.
- The final DOCX does not contain unrelated `双栈`, `算术表达式`, or `空栈` wording.
- The final DOCX contains Huffman/WPL wording.
- The final DOCX inserts one latest real run screenshot after rerun, not older historical screenshots.
- Existing original images are preserved.
