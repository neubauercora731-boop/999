# Expected Report Notes

The final DOCX should not be a standalone regenerated report. It should be the teacher template with appended content in the existing sections:

- `【代码】` under `//实现代码：`
- `【运行截图】` under `实验结果与分析`
- `【问题及思考】` under `问题及思考`

The inserted code should be readable and copyable.
