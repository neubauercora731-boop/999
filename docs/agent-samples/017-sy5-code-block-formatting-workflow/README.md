# 017 sy5 code block formatting workflow

This sample captures the sy5 sequence-list DOC delivery lesson: preserving the teacher template is not enough; inserted code must remain readable, line-oriented, and copyable.

The accepted artifact must:

- Preserve the original teacher document snippets.
- Insert generated content only in the intended sections.
- Use `【代码】`, `【运行截图】`, and `【问题及思考】` labels.
- Never include `系统填写`.
- Store code as many short DOCX paragraphs instead of one compact paragraph.
- Include the real run screenshot media.
